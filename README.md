# Soft Ink

A warm, calm theme for VS Code, inspired by the code blocks in the Claude app.

If you like how code looks when Claude shows it to you, with soft purple keywords, orange types, blue functions, green strings and cyan numbers on a quiet background, Soft Ink brings that same feel into your editor.

Comes in two variants:

- **Soft Ink Dark**: deep charcoal background, matching the Claude app in dark mode
- **Soft Ink Light**: warm cream background, matching the Claude app in light mode

## Install

1. Download the latest `.vsix` file from [Releases](https://github.com/massi1024/soft-ink-theme/releases).
2. In VS Code, open the Extensions panel (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Click `...` at the top right → **Install from VSIX...** and pick the file.
4. Press `Ctrl+K` then `Ctrl+T` (`Cmd+K` `Cmd+T` on Mac) and choose **Soft Ink Dark** or **Soft Ink Light**.
